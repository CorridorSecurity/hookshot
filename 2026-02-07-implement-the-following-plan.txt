│                                                                              │
│ Add Agent Trace Schema Support to Hookshot                                   │
│                                                                              │
│ Context                                                                      │
│                                                                              │
│ https://github.com/cursor/agent-trace is an open specification (v0.1.0) for  │
│ tracing AI-generated code. It defines a vendor-neutral format for recording  │
│ which parts of code were written by AI vs humans, linking to agent           │
│ conversations, and tracking line-level attribution.                          │
│                                                                              │
│ Hookshot already intercepts file edits from AI coding agents (Claude Code,   │
│ Cursor, Cascade, Droid) via its OnAfterFileEdit unified handler. Adding      │
│ agent-trace support lets hookshot users automatically generate trace records │
│  when AI agents edit files — connecting the security/observability layer     │
│ (hookshot) with the attribution layer (agent-trace).                         │
│                                                                              │
│ Plan                                                                         │
│                                                                              │
│ 1. Create agenttrace/ package with Go types mirroring the schema             │
│                                                                              │
│ New file: agenttrace/types.go                                                │
│                                                                              │
│ Define Go structs matching the agent-trace JSON schema:                      │
│ - TraceRecord — top-level record (version, id, timestamp, vcs, tool, files,  │
│ metadata)                                                                    │
│ - File — path + conversations array                                          │
│ - Conversation — url, contributor, ranges, related resources                 │
│ - Range — start_line, end_line, content_hash, optional contributor override  │
│ - Contributor — type (human/ai/mixed/unknown) + model_id                     │
│ - Tool — name + version                                                      │
│ - Vcs — type (git/jj/hg/svn) + revision                                      │
│ - RelatedResource — type + url                                               │
│ - String constants for ContributorType and VcsType enums                     │
│                                                                              │
│ All types use json struct tags matching the spec exactly. Optional fields    │
│ use omitempty.                                                               │
│                                                                              │
│ New file: agenttrace/doc.go — Package documentation with usage examples.     │
│                                                                              │
│ 2. Add a Recorder for building trace records from hookshot hooks             │
│                                                                              │
│ New file: agenttrace/recorder.go                                             │
│                                                                              │
│ A Recorder accumulates file edit information across multiple hook            │
│ invocations and builds a TraceRecord:                                        │
│                                                                              │
│ type Recorder struct { ... }                                                 │
│                                                                              │
│ func NewRecorder(tool *Tool) *Recorder                                       │
│ func (r *Recorder) Record(file, conversationURL string, contributor          │
│ Contributor, ranges []Range)                                                 │
│ func (r *Recorder) Build(vcs *Vcs) TraceRecord                               │
│ func (r *Recorder) Reset()                                                   │
│                                                                              │
│ - Record() adds a conversation entry for a file                              │
│ - Build() produces a complete TraceRecord with UUID, timestamp, and all      │
│ accumulated data                                                             │
│ - Reset() clears accumulated data for the next trace cycle                   │
│                                                                              │
│ No import of the root hookshot package (avoids circular deps). Users call it │
│  from their hookshot handlers directly.                                      │
│                                                                              │
│ 3. Add file-based storage for trace records                                  │
│                                                                              │
│ New file: agenttrace/store.go                                                │
│                                                                              │
│ Simple JSON file I/O:                                                        │
│                                                                              │
│ func WriteTrace(path string, record TraceRecord) error   // Write single     │
│ trace to file                                                                │
│ func ReadTrace(path string) (TraceRecord, error)          // Read single     │
│ trace from file                                                              │
│                                                                              │
│ Uses only stdlib (encoding/json, os). Maintains the zero-dependency          │
│ constraint.                                                                  │
│                                                                              │
